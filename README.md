# Portfolio – how to use
1. Open the folder in VS Code, install the "Live Server" extension, right-click index.html > Open with Live Server.
2. Replace "Your Name" and the About details in index.html.
3. Put your photo at assets/profile.jpg and your CV at assets/cv.pdf.
4. Add graphic design pictures to assets/projects/, then add a line for each in js/main.js (projects list).
5. Add certificate pictures to assets/certificates/ and list them in js/main.js.
6. Replace each "#" in the socials list (js/main.js) with your Facebook, Instagram, LinkedIn, GitHub links.
7. Contact form: create a free form at formspree.io and replace YOUR_FORM_ID in index.html.
8. Deploy free: push the folder to GitHub, then Settings > Pages > Deploy from branch (main). Share the URL.
